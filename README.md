# BAWZ PH

> **Raw Like A Boss.**

A modern, responsive website for **BAWZ PH**, a Philippine-based dance group founded in 2019. Built to showcase the team's story, achievements, services, events, and competitive journey.

---

## Features

- Responsive design for desktop, tablet, and mobile
- Smooth scrolling navigation
- Interactive mobile menu
- Competition showcase with performance links
- Event and service highlights
- Modern dark-themed UI
- Lightweight vanilla JavaScript

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript

---

## 📂 Sections

### Home
Landing page featuring the BAWZ PH identity and call-to-action.

### About
Overview of the team's history, leadership, and growth.

### Competitions
Showcases local and international competition achievements.

### Services
Brand collaborations, sponsorships, partnerships, and bookings.

### Events
Community classes, showcases, and dance productions.

### Contact
Direct contact information and social media links.

---

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/jerico-de/bawz-ph.git
```

2. Open the project folder

```bash
cd bawz-ph
```

3. Launch `index.html` in your browser.
